# BlitzMD — быстрый просмотр Markdown в Total Commander

[English](README.md) | **Русский**

---

**BlitzMD** — бесплатный плагин с открытым кодом для **просмотра Markdown файлов в
[Total Commander](https://www.ghisler.com)** (Lister-плагин, WLX).

Нажмите **F3** на `.md`-файле
или откройте быстрый просмотр **Ctrl+Q** — файл сразу показывается так, как его рисует GitHub:
таблицы, списки задач, сноски, alerts, формулы, диаграммы Mermaid, подсветка кода, эмодзи и
тёмная тема. BlitzMD рисует документ сам, через Direct2D и DirectWrite: без браузерного движка,
без WebView2 и .NET, ничего дополнительно устанавливать не нужно.

## Коротко

| | |
|---|---|
| Что это | Lister-плагин (WLX) для Total Commander для просмотра Markdown-файлов |
| Открывает | `.md`, `.markdown`, `.mdown`, `.mkd`, `.mkdn`, `.mdwn`, `.mdtxt`, `.mdtext`, `.rmd` |
| Где работает | Lister (F3), быстрый просмотр (Ctrl+Q), эскизы, печать |
| Что показывает | GitHub Flavored Markdown (GFM 0.29) и расширения GitHub: alerts, сноски, формулы, Mermaid, эмодзи, HTML из README |
| Total Commander | 64-битный (`blitzmd.wlx64`) и 32-битный (`blitzmd.wlx`), оба в одном архиве |
| Windows | Windows 10 версии 1703 и новее, Windows 11 |
| Движок | Нативный C++: разбор [md4c](https://github.com/mity/md4c), отрисовка Direct2D + DirectWrite |
| Зависимости | Нет: только системные библиотеки |
| Интерфейс | Английский и русский |
| Лицензия | MIT, бесплатно |

## Установка

1. Скачайте `blitzmd.zip` из [последнего релиза](../../releases/latest).
2. Откройте архив в Total Commander (Enter на файле) — TC предложит установить плагин, подтвердите.
3. Готово: F3 или Ctrl+Q на `.md`-файле.

Вручную: распакуйте архив в любую папку и добавьте `blitzmd.wlx64` (или `blitzmd.wlx` для
32-битного Total Commander) в *Конфигурация → Настройка → Плагины → Плагины просмотра (WLX)*.

## Возможности

### GitHub Flavored Markdown

Все конструкции спецификации GFM 0.29: заголовки ATX/Setext, абзацы, цитаты, списки
(маркированные, нумерованные с любым начальным номером, вложенные, «тесные» и «свободные»),
списки задач `- [x]`, блоки кода (fenced и с отступом), таблицы с выравниванием, зачёркивание,
ссылки всех видов (inline, reference, autolink, расширенные autolink `www.` / `https://` /
e-mail), изображения, HTML-сущности, экранирование, жёсткие переносы. Проверено официальным
набором тестов спецификации (см. [Тестирование](#тестирование)).

### Расширения GitHub

- **Alerts**: `> [!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]` — с иконками
  Octicons.
- **Сноски** `[^1]`, включая многоабзацные (с кодом и списками внутри), с обратными ссылками ↩.
- **Формулы** `$…$`, `` $`…`$ ``, `$$…$$` и блоки ```` ```math ```` свёрстаны по правилам TeX
  шрифтом Cambria Math (его таблица OpenType MATH), как MathJax на GitHub: дроби, корни,
  индексы и пределы у `\sum` / `\int` / `\lim`, растягиваемые скобки `\left…\right`, матрицы и
  `cases` / `aligned`, акценты и фигурные скобки сверху/снизу, `\text`, `\mathbb` / `\mathcal` /
  `\mathbf`, пробелы, `\color`, `\boxed`. Неизвестные команды видны как есть (красным, как в
  MathJax); копирование и поиск дают исходный TeX.
- **Диаграммы Mermaid** (блоки ```` ```mermaid ````) раскладывает и рисует сам плагин, без
  браузера и JavaScript, в цветах светлой и тёмной темы Mermaid на GitHub:
  - flowchart / graph: узлы всех форм, все виды связей (концы, толщина, пунктир, длина,
    подписи), подграфы (со своим направлением, если в них не ведут связи снаружи), `classDef` /
    `class` / `:::` / `style` / `linkStyle`, Markdown и HTML в подписях; послойная раскладка
    (Sugiyama);
  - sequenceDiagram: участники и актёры, все виды стрелок, активации, заметки, `autonumber`,
    `loop` / `alt` / `opt` / `par` / `critical` / `break` / `rect`, `box`, `create` / `destroy`;
  - classDiagram, stateDiagram, erDiagram, requirementDiagram, C4 (Context, Container,
    Component, Dynamic, Deployment);
  - pie, journey, gantt, timeline, mindmap, quadrantChart, xychart-beta, sankey-beta,
    radar-beta, treemap-beta, packet-beta, gitGraph, kanban, block-beta, architecture-beta;
  - treeView-beta, ishikawa-beta, cynefin-beta, venn-beta, wardley-beta, eventmodeling,
    swimlane-beta, railroad-beta (и его формы EBNF, ABNF и PEG), info.

  Диаграммы масштабируются и открываются на всё окно, как картинки; копирование даёт исходный
  текст, поиск подсвечивает подписи. Неподдержанный тип или ошибка — блок кода с пометкой о
  причине. Темы Mermaid (`%%{init: {theme: ...}}%%`) не применяются: цвета всегда из темы
  GitHub, светлой или тёмной, как у документа. Пределы — как у Mermaid: 50 000 символов и 500
  связей во flowchart (у остальных типов — 2000 связей).
- **Эмодзи-коды** `:rocket:` → 🚀 (полная база GitHub gemoji, 1900+ кодов), цветные эмодзи.
- **Флаги стран** 🇷🇺 🇺🇸 🇯🇵 и 🏴󠁧󠁢󠁥󠁮󠁧󠁿 🏴󠁧󠁢󠁳󠁣󠁴󠁿 🏴󠁧󠁢󠁷󠁬󠁳󠁿: в шрифте эмодзи Windows их нет (видны две буквы), поэтому
  BlitzMD рисует их из встроенного набора Twemoji (262 флага).
- **Якоря заголовков** как на GitHub (`#установка`, дубликаты `-1`, `-2`) и переходы по ним.
- **Подсветка синтаксиса** в блоках кода: около 70 языков (250+ названий и расширений: C/C++,
  C#, Java, Kotlin, Swift, Go, Rust, JavaScript/TypeScript, Python, Ruby, PHP, Lua, SQL,
  Pascal/Delphi, Bash, PowerShell, bat, HTML/XML, CSS, JSON, YAML, TOML, INI, diff, Dockerfile,
  Makefile, CMake, ассемблер, LaTeX и другие), цвета как на GitHub.
- **Изображения для тёмной/светлой темы**: `#gh-dark-mode-only`, `<picture><source media>`.
- **YAML front matter** (Jekyll, Hugo, Docusaurus) показывается таблицей «ключ — значение».

### HTML, который используют README

`<div align="center">`, `<p align>`, `<h1 align>`, `<img width height align>`, `<picture>`,
`<details>` / `<summary>` (раскрываются кликом), `<kbd>`, `<sup>`, `<sub>`, `<mark>`, `<ins>`,
`<del>`, `<br>`, `<hr>`, `<a name>`, HTML-таблицы (`colspan`), `<dl>`, комментарии. `<script>`,
`<style>`, `<iframe>` и подобное не выполняется и не показывается.

### Изображения

PNG, JPEG, GIF, BMP, ICO, TIFF, WebP (через Windows Imaging Component) и SVG, включая текст и
логотипы: бейджи shields.io и GitHub Actions выглядят как на GitHub. `data:`-URI, относительные и
абсолютные пути, пробелы и кириллица в именах файлов. Анимированные GIF проигрываются, пока
видны на экране. Картинки из интернета загружаются в фоне и кешируются (отключаемо); ради
безопасности они никогда не запрашиваются с этого компьютера и из локальной сети.

### Просмотр

- Тема следует Total Commander (включая тёмный режим TC 10 и новее), можно задать светлую или
  тёмную явно.
- Плавная прокрутка, полоса прокрутки с отметками найденного текста.
- Выделение мышью (двойной щелчок — слово, тройной — абзац), копирование (Ctrl+C, меню TC).
- Поиск через диалог Lister (F7, F3 / Shift+F3): регистр, целые слова, назад; все совпадения
  подсвечиваются, свёрнутые `<details>` раскрываются.
- Ссылки: веб-ссылки открываются в браузере, `#якоря` прокручивают документ, ссылки на другие
  `.md` открываются в этом же окне (назад — Backspace или Alt+←), остальные файлы — связанной
  программой, а программы и скрипты — после подтверждения. Адрес ссылки показывается внизу окна.
- Широкие таблицы и длинные строки кода (при выключенном переносе) прокручиваются вбок
  (Shift+колесо); у блоков кода есть кнопка «Копировать» и номера строк (при копировании их нет).
- Автообновление: когда редактор сохраняет файл, просмотр перечитывает его и остаётся на том же
  месте.
- Масштаб: Ctrl+колесо, Ctrl+`+`, Ctrl+`-`, Ctrl+0 (запоминается).
- Картинки и диаграммы масштабируются прямо в своей рамке (Ctrl+колесо над ними, перетаскивание,
  двойной щелчок — сброс) или открываются на всё окно.
- Процент прокрутки в заголовке Lister, переход к проценту из меню TC.
- Печать (меню Lister «Файл → Печать»): разбивка на страницы без разрыва строк и строк таблиц.
- Эскизы для режима эскизов Total Commander.
- Контекстное меню: оглавление (переход к любому заголовку), копирование, адрес ссылки или
  картинки, копирование блока кода, тема, перенос кода, номера строк, ширина текста, картинки из
  интернета, перечитать (F5), автообновление, открыть в редакторе, настройки.
- Окно настроек: тема, шрифты, размер, масштаб, ширина текста, перенос и номера строк в коде,
  подсветка, формулы, эмодзи-коды, картинки из интернета, автообновление, плавная прокрутка,
  рисование через GPU. Изменения сразу видны во всех открытых окнах просмотра; «ОК» сохраняет
  их, «Отмена» возвращает прежние.
- Кодировки: UTF-8 (с BOM и без), UTF-16 LE/BE (с BOM и без), ANSI (например, Windows-1251).

## Скорость

BlitzMD точно размечает только видимую часть документа, остальное оценивает и уточняет в фоне,
поэтому даже многомегабайтный файл открывается за доли секунды. Картинки декодируются в фоновых
потоках, а память под них ограничена (192 МБ, в 32-битной версии 96 МБ): давно не показанные
картинки выгружаются и декодируются заново, когда снова попадают на экран.

Замеры на AMD Ryzen 9 5900HX, Windows 11, от вызова Total Commander до первого кадра на экране:

| Документ | Открывается за | Память |
|---|---|---|
| README в стиле GitHub с бейджами и картинками (`samples/gfm/02-github-readme.md`) | 40 мс | +22 МБ |
| 2,4 МБ Markdown, 18 000 абзацев (`samples/gfm/09-large-document.md`) | 0,12 с | +51 МБ |

## Настройки

Меняются в окне настроек (контекстное меню → «Настройки…»), часть — прямо пунктами меню.
Хранятся в `blitzmd.ini` рядом с `wincmd.ini` (секция `[blitzmd]`); файл создаётся при первом
изменении, все ключи необязательны.

| Ключ | По умолчанию | Описание |
|---|---|---|
| `Theme` | `0` | `0` — как в Total Commander (или Windows), `1` — светлая, `2` — тёмная |
| `Font` | `Segoe UI` | Шрифт текста |
| `MonoFont` | *(авто)* | Моноширинный шрифт; Cascadia Mono, если установлен, иначе Consolas |
| `FontSize` | `16` | Базовый размер шрифта (как 16 px на GitHub) |
| `Zoom` | `100` | Масштаб в процентах (30–400) |
| `MaxWidth` | `900` | Максимальная ширина текста; `0` — на всю ширину окна |
| `WrapCode` | `-1` | Перенос длинных строк кода: `-1` — как «Перенос строк» в Lister, `0` / `1` — выкл / вкл |
| `LineNumbers` | `1` | Номера строк в блоках кода из двух и более строк |
| `AutoReload` | `1` | Перечитывать файл, когда он меняется на диске |
| `RemoteImages` | `1` | Загружать картинки из интернета (http/https) |
| `SmoothScroll` | `1` | Плавная прокрутка |
| `EmojiShortcodes` | `1` | Заменять `:код:` на эмодзи |
| `Math` | `1` | Формулы `$…$` |
| `Mermaid` | `1` | Диаграммы Mermaid (`0` — показывать исходный текст) |
| `SyntaxHighlight` | `1` | Подсветка синтаксиса |
| `HardwareRendering` | `0` | `1` — рисовать через GPU (для очень больших окон, 4K); программный Direct2D быстрее открывается и расходует меньше памяти |

## Вопросы и ответы

**Как смотреть Markdown-файлы в Total Commander?**
Установите BlitzMD (см. [Установка](#установка)) и нажмите F3 на `.md`-файле или Ctrl+Q, чтобы
показать его в соседней панели.

**Нужен ли BlitzMD браузер, Internet Explorer, WebView2 или .NET?**
Нет. Markdown разбирает md4c, а документ рисуется собственными средствами Windows — Direct2D и
DirectWrite. Плагин — одна DLL, ничего дополнительно ставить не нужно.

**Показывает ли он Markdown так же, как GitHub?**
Да, это его цель: типографика и цвета GitHub (светлые и тёмные), таблицы и списки задач GFM,
alerts, сноски, формулы, диаграммы Mermaid, эмодзи и HTML, которым пользуются README.

**Работает ли с 32-битным Total Commander?**
Да. В архиве есть `blitzmd.wlx` (32-бит) и `blitzmd.wlx64` (64-бит); Total Commander установит
нужный.

**Есть ли тёмная тема?**
Да. По умолчанию тема следует тёмному режиму Total Commander (или Windows); её можно задать
светлой или тёмной явно.

**Рисует ли он диаграммы Mermaid и формулы LaTeX?**
Да, и то и другое рисует сам плагин, без JavaScript: 30 типов диаграмм Mermaid и формулы TeX,
свёрстанные шрифтом Cambria Math.

**Безопасно ли открывать чужие Markdown-файлы?**
Скрипты в HTML никогда не выполняются. Ссылки на программы и скрипты, а также на общие папки
других компьютеров открываются только после подтверждения. Картинки из интернета никогда не
запрашиваются с этого компьютера и из локальной сети, а их загрузку можно отключить.

**Можно ли редактировать Markdown?**
Нет, BlitzMD только показывает. «Открыть в редакторе» в его контекстном меню открывает файл в
программе, которой Windows правит `.md`-файлы, а F4 в Total Commander — во встроенном редакторе
TC.

**BlitzMD бесплатный?**
Да, это открытый код под лицензией MIT.

## Сборка

Нужны Visual Studio 2022 или 2026 с компонентом C++ и CMake (идёт с Visual Studio). Всё остальное
лежит в репозитории (md4c — в `third_party`), сеть при сборке не нужна.

```powershell
# x64 Release -> out\build\x64-release\blitzmd.wlx64
powershell -File scripts\build.ps1

# x64 + x86 и упаковка в dist\blitzmd.zip (для установки из TC)
powershell -File scripts\build.ps1 -Arch all -Package
```

Папку проекта можно открыть и в Visual Studio (CMake-пресеты `x64-release`, `x86-release`).

## Тестирование

Весь набор тестов (его же запускает CI):

```powershell
powershell -File scripts\test.ps1                                          # x64
powershell -File scripts\test.ps1 -Build out\build\x86-release -Quick     # x86, меньше фаззинга
```

Отдельные проверки — инструмент `mdview_test.exe`, который собирается вместе с плагином:

```powershell
$t = "out\build\x64-release\mdview_test.exe"
& $t spec tests\spec\gfm-spec.txt           # тесты спецификации GFM 0.29 (672 примера)
& $t spec tests\spec\commonmark-spec.txt    # тесты CommonMark 0.31.2
& $t render samples\gfm\02-github-readme.md out.png --width 900 [--dark] [--zoom 1.5]
& $t pages  samples\gfm\05-tables.md page   # постраничная разбивка как при печати
& $t bench  samples\gfm\09-large-document.md
& $t fuzz   2000                            # случайные документы: разбор + разметка + отрисовка
& $t plugin out\build\x64-release\blitzmd.wlx64 README.md shot.png "поиск"   # сам DLL, как его вызывает TC
& $t settings out\build\x64-release\blitzmd.wlx64 README.md out\tmp\set\s   # окно настроек
& $t zoom out\build\x64-release\blitzmd.wlx64 tests\zoom.md out\tmp\zoom\z  # масштаб картинок
& $t mermaid samples\gfm\20-mermaid-flowchart.md   # диаграммы: разбор, раскладка, враждебный ввод, фаззинг
& $t math samples\gfm\18-math.md                   # формулы: разбор TeX, вёрстка, фаззинг
& $t mmd diagram.mmd out.png [--dark]              # одна диаграмма Mermaid в PNG
out\build\x64-release\highlight_test.exe -q   # подсветка синтаксиса: 1,4 млн проверок, фаззинг
```

Результат по спецификации GFM: все 604 примера, не связанных с «сырым» HTML, совпадают с
эталоном (примеры с HTML намеренно интерпретируются, а не выводятся как есть). Прогон под
AddressSanitizer (`-DMDVIEW_ASAN=ON`) и фаззинг чисты.

`scripts\screenshots.ps1` заново снимает скриншоты README с документов в `docs/screenshots/`.
`samples/gfm/` — документы для проверки на глаз: обзор всей спецификации, README в стиле GitHub,
alerts, сноски и формулы, 45+ языков программирования, таблицы, списки, типографика на 15+ языках
(включая письмо справа налево), пограничные случаи и документ на 2,5 МБ.

## Непрерывная сборка и выпуск версии

GitHub Actions (`.github/workflows/ci.yml`) на каждый push и pull request собирает x64 и x86,
запускает `scripts\test.ps1` и прикладывает к запуску готовый `blitzmd.zip`.

Выпуск версии:

1. Поменять номер в `CMakeLists.txt` (`project(blitzmd VERSION x.y.z ...)`) — он попадает и в
   ресурс версии DLL, и в `pluginst.inf` при упаковке.
2. Закоммитить, поставить тег и отправить его: `git tag vx.y.z`, `git push origin vx.y.z`.
3. CI проверит, что тег совпадает с версией, соберёт, прогонит тесты и опубликует GitHub Release
   с `blitzmd.zip`, который Total Commander устанавливает сам.

## Архитектура

```
src/plugin.cpp        экспорт WLX: ListLoad(W), ListLoadNext(W), ListSearchText(W),
                      ListSendCommand, ListPrint(W), ListGetPreviewBitmap(W), ...
src/core/parser.*     md4c → дерево блоков; HTML-подмножество GitHub, эмодзи, якоря, сноски
src/core/html.*       токенизатор HTML
src/core/texmath.*    разбор TeX-формул в дерево атомов
src/core/mathlayout.* вёрстка формул по правилам TeX с таблицей OpenType MATH (Cambria Math)
src/core/flags.*      флаги-эмодзи из встроенного набора Twemoji (src/twemoji-flags.bin,
                      собирается scripts/gen_flags.py)
src/core/highlight.*  подсветка синтаксиса
src/core/layout.*     разметка: DirectWrite, точная у видимой части, оценка остального
src/core/render.*     отрисовка Direct2D (темы GitHub Primer)
src/core/images.*     WIC, SVG, фоновая загрузка по http(s) с кешем
src/core/zoom.*       масштаб картинок и диаграмм в их рамке и на всё окно
src/core/mermaid*     диаграммы Mermaid: разбор (по файлу на тип), построение сцены
src/core/graphlayout.* послойная раскладка графов (Sugiyama) с кластерами
src/core/diagram.*    сцена диаграммы: фигуры, пути, текст DirectWrite; отрисовка по теме
src/core/viewer.*     окно Lister: прокрутка, выделение, ссылки, поиск, меню
src/core/settings*    настройки (blitzmd.ini) и окно настроек
src/core/print.*      печать
third_party/md4c      md4c 0.6.0 с несколькими правками совместимости с GitHub
```
