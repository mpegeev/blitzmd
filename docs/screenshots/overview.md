<h1 align="center">BlitzMD</h1>

<p align="center"><b>A fast Markdown viewer for Total Commander</b><br>
<sub>Lister plugin · F3 and Ctrl+Q · no browser engine inside</sub></p>

<p align="center">
  <img src="badges/version.svg" alt="version 1.0.0">
  <img src="badges/license.svg" alt="license MIT">
  <img src="badges/total-commander.svg" alt="Total Commander 32/64-bit">
  <img src="badges/windows.svg" alt="Windows 10 | 11">
</p>

Press <kbd>F3</kbd> on a `.md` file, or <kbd>Ctrl</kbd>+<kbd>Q</kbd> for Quick View, and the document
shows the way GitHub renders it :zap:

| What | How BlitzMD shows it |
|---|---|
| Tables, task lists, footnotes | GitHub Flavored Markdown 0.29 |
| Alerts, emoji :rocket:, math | GitHub's extensions |
| Mermaid diagrams | 30 types, drawn by the plugin itself |
| Code blocks | about 70 languages, line numbers |
| Light and dark themes | following Total Commander |

- [x] Opens a 2.4 MB document in 0.12 s
- [x] Pictures: PNG, JPEG, GIF, WebP, SVG
- [x] Search, printing, thumbnails
- [ ] Editing: BlitzMD is a viewer

> [!TIP]
> In Quick View (<kbd>Ctrl</kbd>+<kbd>Q</kbd>) the preview follows the cursor as you move through
> the files.
