# Вложенные списки

## Маркированный список с вложенностью

- Уровень 1, элемент A
  - Уровень 2, A1
  - Уровень 2, A2
    - Уровень 3, A2a
    - Уровень 3, A2b
- Уровень 1, элемент B
  - Уровень 2, B1
- Уровень 1, элемент C

## Нумерованный с вложенностью

1. Первый
2. Второй с подсписком:
   1. 2.1
   2. 2.2
   3. 2.3
3. Третий

## Смешанный

1. Шаг 1
   - Подпункт A
   - Подпункт B
2. Шаг 2
   - Подпункт C
     - Глубже C-1
     - Глубже C-2
3. Шаг 3

## Список с код-блоками внутри

1. Установить зависимости:

   ```bash
   cmake --version
   git --version
   ```

2. Склонировать репозиторий:

   ```bash
   git clone https://github.com/example/repo.git
   cd repo
   ```

3. Собрать и запустить:

   ```bash
   cmake -B build
   cmake --build build
   ```

## Список с цитатой и параграфом внутри

1. Первый пункт с дополнительным абзацем.

   А вот и второй абзац того же пункта. Должен быть на том же уровне.

2. Второй пункт с цитатой:

   > Цитата внутри пункта списка.
   > Несколько строк.

3. Третий пункт без особенностей.
