## С форматированием в ячейках

| Свойство     | Тип            | Значение по умолчанию |
|--------------|----------------|----------------------|
| `enabled`    | **boolean**    | `true`               |
| `timeout`    | **integer**    | `30`                 |
| `name`       | **string**     | *(пустая строка)*    |
| `tags`       | **array**      | `[]`                 |
| `verbose`    | ~~boolean~~    | удалено в v2.0       |

## Длинные значения в ячейках

| Имя файла | Описание |
|-----------|----------|
| `plugin.cpp` | Основной модуль с экспортами WLX и логикой загрузки markdown |
| `CMakeLists.txt` | Конфигурация сборки, FetchContent для md4c, статическая CRT |
| `plugin.def` | Module definition для нескалькаемых экспортов |
